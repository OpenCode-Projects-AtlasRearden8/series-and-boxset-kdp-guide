# Worksheet W2 — boxset costs

A one-page planner for a print (and e-book) bundle of your series.
Chapters 2 and 3 carry the logic; this sheet carries your numbers.

## 2. The fit check

```text
total words           = ____________
pages of books        = total words ÷ ______ (wpp for chosen trim)
extras allowance      = about 30–50 pages of front/back matter + dividers
bundle page count     = book pages + extras = ____________

print ceiling      ≈ 800 pages (KDP figure is 828 as of writing —
                     current number in KDP help)
fits?               [ ] yes  [ ] no — go to section 3
```

## 3. If it doesn't fit, in order of effort

- [ ] Wider trim (6 × 9 or 6.14 × 9.21): more words per page, fewer pages
- [ ] Tighter typesetting at the same trim (330 → 380 wpp: ~100 pages
      saved per 250,000 words)
- [ ] Split into two print bundles (*Parts One and Two*) — or bundle
      books 1–3 only, and save 4–6 for a second print product
- [ ] Drop the print bundle idea; publish only the e-book bundle (no
      page ceiling online)

Recompute section 2 after any of these (same sheet, fresh numbers).

~$3.92, at $19.99 → ~$5.72, at $24.99 → ~$8.72.

## 5. Spine note for the cover sketch

```text
pages × 0.0025 (cream) or × 0.0022 (white) = ______ inches
KDP's own cover template prints the exact spine once page count is set
```

## 6. The e-book bundle rung

```text
singles sum (e-books)      = $ ____ × ___ books = $ ____
bundle rung                = $ ____ (___% band) → $ ____ per copy
```

Band sanity: $9.99 pays about **$6.99**; $14.99 pays only about
**$5.25** — check chapter 4's table before you "add a couple dollars
for the discount". A jumbo omnibus above ~**$20** escapes the dead
zone; three-book bundles usually belong at $9.99.

## 7. The decision box

- [ ] Contents chosen (books 1–3 / 1–4 / plus-extras)
- [ ] Bundle title + subtitle ("Books 1–4") without a series *number*
- [ ] Fresh listing written for the bundle (not book 1's paste)
- [ ] Print fit check passed (section 2 or a split in section 3)
- [ ] Price ladder set (section 4 + 6, [chapter 4](04-pricing-ladders.md))
- [ ] KU enrollment choice made for the bundle itself
      ([chapter 8](08-wide-vs-ku-round-numbers.md))
- [ ] Series page: bundle appears (number blank), singles ordered right
- [ ] Back matter of every book updated to mention the bundle
